# אתר משרד עורכי הדין אלעד אביטן

## 🚀 התקנה והפעלה

### 1. התקנת תלויות

```bash
npm install
```

### 2. הגדרת מסד הנתונים

```bash
npm run setup
```

פקודה זו תיצור:
- תיקיית `data/` עם מסד הנתונים
- קובץ `.env.local` עם הגדרות אבטחה
- משתמש admin ראשוני

**פרטי כניסה ראשוניים:**
- שם משתמש: `admin`
- סיסמה: `admin123`
- **שנה את הסיסמה מיד לאחר ההתחברות הראשונה!**

### 3. הגדרת ניתוח AI (אופציונלי — לחוות הדעת האוטומטית)

ניתוח ה-AI של חוות הדעת הראשונית משתמש במודל Claude של Anthropic. כדי להפעילו:

1. השג מפתח API בכתובת https://console.anthropic.com
2. פתח את הקובץ `.env.local` שנוצר בשלב הקודם, והדבק את המפתח:
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```
3. הפעל מחדש את השרת.

ללא מפתח, כל שאר המערכת עובדת כרגיל — רק כפתור "נתח אוטומטית" בחוות הדעת יציג
הודעה שהתכונה אינה מוגדרת. ניתן לבחור מודל אחר עם `ANTHROPIC_MODEL` (ברירת מחדל: `claude-opus-5`).

### 4. הוספת תמונות

העתק את תמונות הפרופיל לתיקייה `public/images/`:
- `hero.jpg` - תמונת הרקע הראשית (Hero)
- `about.jpg` - תמונה לסקציית אודות

### 5. הפעלה בסביבת פיתוח

```bash
npm run dev
```

גלוש ל: http://localhost:3000

### 6. בנייה לייצור

```bash
npm run build
npm start
```

## 📋 תכונות האתר

### אתר ראשי (ציבורי)
- דף בית מלא בעברית עם RTL
- סקציות: Hero, אודות, תחומי עיסוק, יתרונות, יצירת קשר
- טופס יצירת קשר
- עיצוב מקצועי בצבעי זהב-שחור

### פורטל לקוחות (`/portal`)
- כניסה עם שם משתמש וסיסמה
- לוח בקרה עם רשימת תיקים
- צפייה בסטטוס תיק + ציר זמן של עדכונים
- העלאת קבצים (PDF, Word, תמונות, Excel)
- הורדת מסמכים ממשרד עורכי הדין
- שינוי סיסמה אישית

### פאנל ניהול (`/admin`)
- ניהול לקוחות (הוספה, מחיקה)
- ניהול תיקים (פתיחה, עדכון סטטוס)
- הוספת עדכונים לתיקים
- העלאת מסמכים ללקוחות
- סטטיסטיקות

### מודול ניהול ליטיגציה (`/admin/litigation`)
ניהול הליך משפטי מקצה לקצה, לפי הצד המיוצג:

**בייצוג תובע:**
1. טופס הכר את הלקוח (זיהוי, צד שכנגד, בדיקת ניגוד עניינים)
2. טופס תיאור המקרה והעובדות כפי שנמסרו מהלקוח
3. מחולל הסכם שכר טרחה (קבוע / שעתי / אחוזים / משולב)
4. מחולל חוות דעת ראשונית על סיכויי התיק — כולל **ניתוח AI אוטומטי**: המערכת
   קוראת את תיאור העובדות (וכן תמונות/צילומי מסך/מסמכי PDF שסומנו מתיק הלקוח),
   מעריכה סיכויים, מנתחת חוזקות וחולשות, מבצעת ניתוח משפטי, מנמקת וממליצה על
   דרך פעולה — הכל מבוסס על מקורות משפטיים אמיתיים מהספרייה. הפלט ממלא את הטופס
   וניתן לעריכה ובקרה לפני הפקת המסמך. **דורש הגדרת `ANTHROPIC_API_KEY`** (ראו למטה).
5. מחולל מכתב התרעה לפני נקיטת הליכים
6. מחולל כתב תביעה (לפי תקנות סדר הדין האזרחי, תשע"ט-2018)
7. מחולל בקשות וסעדים (סעדים זמניים, סילוק על הסף, הארכת מועד ועוד)

**בייצוג נתבע:**
1. הזנת כתב התביעה שהתקבל
2. טופס הכר את הלקוח + הסכם שכ"ט + חוו"ד
3. מחולל כתב הגנה (טענות מקדמיות, מענה סעיף-סעיף, גרסת הנתבע)
4. מחולל בקשות וסעדים

**כלל המקורות המשפטיים:** כל מסמך שנוצר חייב להישען על לפחות 3 מקורות
משפטיים מספריית המקורות המובנית (`lib/legal-sources.js`) — חקיקה ופסיקה
ישראלית אמיתית בלבד, עם מראה מקום וקישור למקור. הכלל נאכף גם בצד השרת.
כל מסמך ניתן להדפסה / שמירה כ-PDF ולהורדה כקובץ Word.
