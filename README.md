# אתר משרד עורכי הדין אלעד אביטן

## 🚀 התקנה והפעלה

### 1. התקנת תלויות

```bash
npm install
```

### 2. הגדרת מסד הנתונים

```bash
npm run setup
```

פקודה זו תיצור:
- תיקיית `data/` עם מסד הנתונים
- קובץ `.env.local` עם הגדרות אבטחה
- משתמש admin ראשוני

**פרטי כניסה ראשוניים:**
- שם משתמש: `admin`
- סיסמה: `admin123`
- **שנה את הסיסמה מיד לאחר ההתחברות הראשונה!**

### 3. הוספת תמונות

העתק את תמונות הפרופיל לתיקייה `public/images/`:
- `hero.jpg` - תמונת הרקע הראשית (Hero)
- `about.jpg` - תמונה לסקציית אודות

### 4. הפעלה בסביבת פיתוח

```bash
npm run dev
```

גלוש ל: http://localhost:3000

### 5. בנייה לייצור

```bash
npm run build
npm start
```

## 📋 תכונות האתר

### אתר ראשי (ציבורי)
- דף בית מלא בעברית עם RTL
- סקציות: Hero, אודות, תחומי עיסוק, יתרונות, יצירת קשר
- טופס יצירת קשר
- עיצוב מקצועי בצבעי זהב-שחור

### פורטל לקוחות (`/portal`)
- כניסה עם שם משתמש וסיסמה
- לוח בקרה עם רשימת תיקים
- צפייה בסטטוס תיק + ציר זמן של עדכונים
- העלאת קבצים (PDF, Word, תמונות, Excel)
- הורדת מסמכים ממשרד עורכי הדין
- שינוי סיסמה אישית

### פאנל ניהול (`/admin`)
- ניהול לקוחות (הוספה, מחיקה)
- ניהול תיקים (פתיחה, עדכון סטטוס)
- הוספת עדכונים לתיקים
- העלאת מסמכים ללקוחות
- סטטיסטיקות
